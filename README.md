<h2 align="center">Flagship Project</h2>

<div align="center">

### 🛃 ClearPort
**AI-powered document automation and exception review for U.S. customs brokers and freight forwarders.**

<img src="https://img.shields.io/badge/Next.js-120A2A?style=for-the-badge&logo=nextdotjs&logoColor=white"/>
<img src="https://img.shields.io/badge/TypeScript-120A2A?style=for-the-badge&logo=typescript&logoColor=FF2E97"/>
<img src="https://img.shields.io/badge/Supabase-120A2A?style=for-the-badge&logo=supabase&logoColor=FFE600"/>
<img src="https://img.shields.io/badge/Gemini-120A2A?style=for-the-badge&logo=googlegemini&logoColor=9D4EDD"/>

</div>

Customs brokers lose hours retyping data from shipment paperwork. ClearPort automates that work with **two-pass AI extraction and validation**, and routes only the doubtful cases to a **human-in-the-loop exception desk**, so people spend their time on exceptions, not data entry.

```mermaid
    C -->|Needs a human| E[🧑‍💼 Exception desk<br/>human-in-the-loop]
    E --> D

    classDef good fill:#120A2A,stroke:#FF9F1C,stroke-width:2px,color:#FFFFFF

```
